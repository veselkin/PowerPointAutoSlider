# PowerPoint AutoSlider

Простая утилита для автоматического перелистывания слайдов в PowerPoint.
Программа сворачивается в трей (область уведомлений) и не мешает работе.

## Возможности
- Автоматический запуск презентации PowerPoint.
- Переключение слайдов каждые 5 секунд (интервал задается в коде).
- Работа в фоновом режиме.
- Управление через иконку в трее.

## Установка
1. Скачайте последнюю версию (`PowerPointAutoSlider.exe`) из раздела [Releases](ссылка).
2. (Опционально) Разместите файл в удобной папке.
3. Убедитесь, что у вас установлен Microsoft PowerPoint.

## Как использовать (3 способа запуска)

### Способ 1 Выбор файла вручную
1. Запустите `PowerPointAutoSlider.exe`.
2. В появившемся окне выберите файл презентации (`.pptx` или `.ppt`).
3. Презентация запустится автоматически.

### Способ 2 Drag-and-Drop на файл программы
1. Найдите файл вашей презентации.
2. Просто перетащите его мышкой прямо на файл `PowerPointAutoSlider.exe`.
3. Программа сразу откроет эту презентацию и начнет показ.

### Способ 3 Использование ярлыка (Рекомендуемый)
1. Нажмите правой кнопкой на `PowerPointAutoSlider.exe` - Создать ярлык.
2. Поместите ярлык на Рабочий стол.
3. Теперь вы можете перетаскивать файлы презентаций на этот ярлык.

 Примечание Перетаскивание файлов на маленькую иконку возле часов (в трее) не поддерживается Windows. Используйте способы выше.

## Управление
- Программа работает в фоне. Ищите иконку (обычно синий экранчик или щит) в системном трее возле часов.
- Всплывающая подсказка покажет название текущего файла.
- Правая кнопка мыши на иконке - Выход, чтобы закрыть программу и остановить таймер.

## Требования
- Windows 10  11
- Microsoft PowerPoint (любая современная версия)
- .NET Framework 4.8
